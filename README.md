# Paradise Nursery

Paradise Nursery is an online plant shopping application built using React and Redux.

Customers can browse houseplants, view plant names and prices, add plants to their shopping cart, adjust quantities, and view the total cost of their purchases.

## Features

- Plant catalog with three categories
- Add to Cart functionality
- Shopping cart with quantity controls
- Dynamic cart totals
- Responsive navigation

## Technologies

- React
- Redux Toolkit
- CSS
